# Macro Solidity Bootcamp Projects

I completed these Solidity projects during the Macro Fellowship Engineering Program from January to February 2022.

| Project | Description |
| --- | --- |
| [Crowdfund](./crowdfund) | A crowdfunding contract that rewards qualifying contributors with NFTs. |
| [ICO](./ico) | A three-tier token sale. |
| [DAO](./dao) | A DAO with one vote per member, proposals that can execute arbitrary calls, and a dedicated mechanism for buying NFTs. |
| [Liquidity Pool](./lp) | A Uniswap v2-style liquidity pool for the token created in the ICO project. |

Macro’s teaching staff audited these projects as part of the program. Their review materials are included in the respective project folders.
